# 03 — 付款方式清單端點

**What to build:** 前端能向後端要一份「這個共同帳本可用的付款方式清單」，內容即時來自該帳本所綁 Google Sheet 的 `付款方式` 分頁。使用者在 Sheet 上新增或刪除一個付款方式，下次要清單時就反映，不需要等任何同步、不需要重啟。

這是明確的取捨：清單的即時性優先於載入速度，因此**不做快取**。

清單取不到不是災難 —— 這個欄位本來就是選填的。端點必須讓呼叫端能分辨「清單是空的」與「讀取失敗」，且不論哪一種都不能讓建立共同支出的流程受影響。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent
