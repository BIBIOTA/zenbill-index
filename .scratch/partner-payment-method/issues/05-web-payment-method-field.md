# 05 — Web 建立共同支出表單上的付款方式欄位

**What to build:** 使用者在 Web 上建立共同支出時，若這筆支出 partner 有出錢、且該帳本提供了付款方式清單，表單就多出一個選填的下拉選單，標籤是 partner 的名字（例如「Zumi 付款方式」）。選了就存下，不選也能正常送出。

關鍵是**這個選填欄位絕不能拖累記帳本身**：清單非同步載入、不擋表單渲染；Google 出問題時欄位停用並說明，其餘欄位照常運作、支出照樣記得成。

編輯既有共同支出時**不顯示**這個欄位 —— 目前的 Sheet 同步沒有「更新既有列的某一格」的能力，允許編輯會造成資料庫與 Sheet 靜默分歧。

**Blocked by:** 04

**Status:** ready-for-agent
