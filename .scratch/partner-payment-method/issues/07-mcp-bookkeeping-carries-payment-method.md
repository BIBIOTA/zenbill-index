# 07 — MCP 記帳帶付款方式

**What to build:** 使用者對 AI agent 說「昨天晚餐 800 對半分，Zumi 用玉山卡付的」時，那張卡會被記下來；沒提到付款方式時，agent 就留空。

這裡最重要的是**不猜**。agent 只轉述使用者明確講出的內容 —— 從「今天吃飯 300」推不出刷哪張卡，硬填只會產生看起來像真的、實際是編的資料。

刻意**不**在工具描述中列出合法清單（工具描述是靜態的，清單一改就過期），也**不**新增查詢清單的工具（為一個選填欄位多開一個工具、多一輪往返，不划算）。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] agent 記帳工具新增一個選填的字串參數，對應 partner 付款方式
- [x] 使用者明確講出付款方式時，該值隨建立請求送達後端並存下
- [x] 使用者未提及時參數留空，agent 不做推測
- [x] 工具描述未列舉合法值，未新增查詢清單的工具
- [x] 既有的 agent 記帳行為（含不得碰觸帳戶餘額的既有邊界）完全未改變
