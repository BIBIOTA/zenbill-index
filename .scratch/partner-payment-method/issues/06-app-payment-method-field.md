# 06 — App 建立共同支出表單上的付款方式欄位

**What to build:** 與 05 完全相同的行為，在 App 上。使用者用哪個裝置記帳都不該有落差。

判定條件、標籤文字、清單來源全部沿用 04 的共用規則，**不得在 App 端另寫一套** —— 兩端行為分歧正是這張票要防的事。

**Blocked by:** 04

**Status:** ready-for-agent

- [x] 建立共同支出表單依 04 的規則決定是否顯示此欄位，未自行實作判定邏輯
- [x] 欄位為選單而非自由輸入，選項來自該帳本的清單
- [x] 欄位標籤取自 04 的標籤函式，顯示 partner 的名字
- [x] 欄位為選填，未選時可正常送出且其他欄位行為不變
- [x] 清單以非同步方式載入，表單在載入期間即可操作與送出
- [x] 清單載入失敗時欄位顯示明確的無法載入說明並停用，其餘欄位與送出流程完全不受影響
- [x] 編輯既有共同支出的畫面不顯示此欄位
- [x] 同一筆支出在 App 與 Web 上的顯示與否、標籤文字一致
